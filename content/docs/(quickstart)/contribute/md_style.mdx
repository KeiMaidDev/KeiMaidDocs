## 标题风格

----

### 使用 ATX 风格的标题（1～6 个 # 号）

```tsx
一级标题 // [!code --]
======= // [!code --]

# 一级标题 // [!code ++]
## 二级标题 // [!code ++]
### 三级标题 // [!code ++]
#### 四级标题 // [!code ++]
```
----

### 最后一个 # 后空一格，标题前后空一行

```jsx
##一个标题 // [!code --]
段落内容…… // [!code --]

前一个段落的内容…… // [!code ++]
+ // [!code ++]
## 一个标题 // [!code ++]
+ // [!code ++]
下一个段落…… // [!code ++]
```
----

### 一篇文章中只应有一个一级标题

```tsx
# 一个一级标题 // [!code --]
- // [!code --]
## 第一个二级标题 // [!code --]
- // [!code --]
Blahblah…… // [!code --]
- // [!code --]
# 又一个一级标题 // [!code --]
- // [!code --]
Blahblah…… // [!code --]

# 一个一级标题 // [!code ++]
+ // [!code ++]
## 第一个二级标题 // [!code ++]
+ // [!code ++]
Blahblah…… // [!code ++]
+ // [!code ++]
## 第二个二级标题 // [!code ++]
+ // [!code ++]
Blahblah…… // [!code ++]
```
