## 中文写作排版风格指南

----

### **CJK** 与 **西文** 之间一律插入一个空格

```tsx
 在Python中，我们使用class关键字来声明类。 // [!code --]
 在 Python中，我们使用 class关键字来声明类。 // [!code --]
 在 Python 中，我们使用 class 关键字来声明类。 // [!code ++]

 他只用了100行不到的代码就实现了那个复杂的功能。 // [!code --]
 他只用了 100 行不到的代码就实现了那个复杂的功能。 // [!code ++]
```

----

### CJK 一律使用全角书写，西文一律使用半角书写

```tsx
 １２３ ＡＢＣ // [!code --]
 123 ABC // [!code ++]

 ﾋﾞﾘﾋﾞﾘ // [!code --]
 ビリビリ // [!code ++]
```

----

### 数字与英文单位之间加空格，与符号单位之间不加空格

```tsx
 我有一块 512GB 的硬盘。 // [!code --]
 我有一块 512 GB 的硬盘。 // [!code ++]

 今天气温 23 ˚C，有 70 % 的可能性下雨。.// [!code --]
 今天气温 23˚C，有 70% 的可能性下雨。 // [!code ++]
```

----

### 全角标点与其它字符之间不加空格

```tsx
 他有一台 Mac 。 // [!code --]
 他有一台 Mac。 // [!code ++]
```

----

### CJK与 **西文符号** 之间加空格

```tsx
 很多人都在学习 C++这门语言。 // [!code --]
 很多人都在学习 C++ 这门语言。 // [!code ++]

 count--表示给 count 变量减 1。 // [!code --]
 count-- 表示给 count 变量减 1。 // [!code ++]
```

----

### 行的开头和结尾不应出现空白字符

```tsx
  这是一行文字。   // [!code --]
这是一行文字。 // [!code ++]
```

----

### 在 CJK 语境下使用全角标点（除数学运算符）

```tsx
 你好,请问<朝花夕拾>这本书还有的卖吗? // [!code --]
 你好，请问《朝花夕拾》这本书还有的卖吗？ // [!code ++]

 Android Studio 从 1.3 版本开始加入了 NDK(Native Development Kit)支持. // [!code --]
 Android Studio 从 1.3 版本开始加入了 NDK（Native Development Kit）支持。 // [!code ++]
 ```

----

###除特殊场合（如代码中）外，不应有两个或更多空格连续出现

```tsx
我喜欢  github // [!code --]
我喜欢 github // [!code ++]
```

----

### 链接与文本之间加空格

```tsx
 可以查询[术语表](/docs/glossary)来找到相关信息 // [!code --]
 可以查询 [术语表](/docs/glossary) 来找到相关信息 // [!code ++]
```
